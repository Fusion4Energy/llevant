# Guide

- [Command line](cli.md): `llevant info | locate | trace | slice | render | materials |
  fingerprint | volume | check | view`
- [Python](python.md): `import llevant`, and `python -m llevant` for the CLI and the
  viewer
- [Viewer](../../crates/llevant-viewer/README.md): `llevant-viewer`, the view file,
  embedding the views, effects

Every command and function takes MCNP numbers (cells, surfaces, materials,
universes) and centimetres.
